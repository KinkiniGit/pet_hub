# 🐾 Pet Hub Care Center - Web Application

A complete web-based application built with **PHP** and **MySQL** for pet care management, pet supplies e-commerce, appointment booking with SMS notifications, and pet adoption services.

---

## ✨ Features

* 🛒 **Pet Mart (E-Commerce): ** Browse pet care products, view pricing, adjust quantities, and manage items in an interactive shopping cart.
* ✂️ **Service Booking System: ** Schedule appointments for veterinary checkups and grooming services with date/time selection.
* 📱 **SMS Integration: ** Automated SMS alerts sent via **Notify.lk API** upon appointment confirmation.
* 🐶 **Pet Adoption Portal: ** Browse available pets looking for homes and submit adoption requests with contact details.
* 📅 **Booking Management: ** View appointment histories, current booking statuses, and SMS delivery tracking.
